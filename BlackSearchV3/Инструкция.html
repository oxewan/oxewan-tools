BlackSearchV3 — Инструкция по установке

Что нам понадобится

  • ПК или телефон (Termux)
  • Python
  • Мозги (желательно)
Для установки на ПК ▼
  1. Скачать архив с GitHub (или архива Контркультуры)
  2. Переносим папку на рабочий стол
  3. Кликаем правой кнопкой мыши по папке и кликаем по пункту "свойства" и копируем
  4. Жмем комбинацию Win + R, в появившемся окне вводим cmd
  5. В терминале вводим cd путь к папке (пример: cd C:\Users\KainoOsint\Desktop\BlackSearchV3)
  6. Вводим python BlackSearchV3.py
  7. Если нет модуля (например, No module named ...), пишем pip install (название модуля)
  8. Готово!
Для установки на Termux ▼
  1. Скачать архив с GitHub (или архива Контркультуры)
  2. Качаем CX-проводник
  3. Заходим в CX-проводник и зажимаем по папке BlackSearchV3
  4. Жмем три точки в правом нижнем углу и нажимаем на пункт "свойства" и копируем
  5. Заходим в Termux и обновляем пакеты: pkg update
  6. Пишем cd путь к папке (пример: cd /storage/emulated/BlackSearchV3)
  7. Вводим python BlackSearchV3.py
  8. Если нет модуля (например, No module named ...), пишем pip install (название модуля)
  9. Готово!

Необходимые модули для утилиты:

  • art
  • rich
  • requests
  • geopy
  • bs4

(Примечание: тут не все модули)
